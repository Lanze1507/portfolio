# Portfolio assets

The current CV is stored here as:

`CV 2026.pdf`

The Open CV and Download CV buttons both point to this file. Open CV opens the PDF in a new tab; Download CV requests the filename `Cristopher_Castellanos_CV_2026.pdf`. Replace `CV 2026.pdf` to update the CV without changing the links.

This directory can also hold future images you own or have permission to use.

## Remaining content

- Add each project's real GitHub repository URL in `index.html`. Replace its disabled GitHub button with an anchor and remove the accompanying placeholder message.
- Add a Live Demo anchor only when a real demo URL is available.

The site uses relative asset paths and needs no build step. For GitHub Pages, publish the repository root containing `index.html`, `style.css`, `script.js`, and this directory.
